# Aadeshwar Café - Design Style Guide

## Design Philosophy

### Heritage Town Aesthetic
Drawing inspiration from Puducherry's French colonial architecture and vibrant street food culture, the design embodies the unique Indo-French fusion that defines Heritage Town. The aesthetic celebrates the warm, earthy tones of colonial buildings while incorporating the lively energy of Indian street food culture.

### Color Palette
**Primary Colors:**
- **Heritage Yellow** (#F4D03F) - Inspired by the iconic yellow ochre buildings of French Quarter
- **Colonial Cream** (#F8F4E6) - Soft off-white reminiscent of stucco walls
- **Terracotta Warmth** (#CD853F) - Earthy brown-orange reflecting roof tiles and pottery
- **Monsoon Green** (#7D8471) - Muted sage green inspired by weathered shutters and foliage

**Accent Colors:**
- **Bougainvillea Pink** (#E8B4B8) - Subtle pink accents inspired by flowering vines
- **Deep Charcoal** (#2C3E50) - For text and strong contrasts
- **Warm White** (#FEFEFE) - Clean backgrounds and highlights

### Typography
**Display Font:** Playfair Display (Serif)
- Used for headings, hero text, and brand elements
- Evokes the elegance of French colonial signage
- Creates emotional impact and heritage feel

**Body Font:** Poppins (Sans-serif)
- Clean, modern readability for menu items and content
- Excellent multilingual support for Tamil, French, and English
- Maintains accessibility while complementing the heritage aesthetic

**Accent Font:** Merriweather (Serif)
- Used for special callouts and testimonials
- Adds warmth and authenticity to customer stories

## Visual Language

### Layout Principles
- **Grid-based Structure:** Reflecting the perpendicular street layout of French Quarter
- **Generous White Space:** Mimicking the courtyard-centered architecture
- **Asymmetrical Balance:** Creating visual interest while maintaining harmony
- **Mobile-First Responsive:** Ensuring accessibility across all devices

### Visual Hierarchy
- **Hero Elements:** Large, impactful imagery with overlay text
- **Content Sections:** Clear separation with consistent spacing
- **Interactive Elements:** Prominent buttons with hover states
- **Navigation:** Clean, minimal design with active state indicators

## Visual Effects & Animation

### Core Libraries Integration
**Anime.js:** Smooth menu filtering animations and card transitions
**Splide.js:** Hero image carousel and food gallery sliders
**ECharts.js:** Customer rating visualizations and order analytics
**p5.js:** Subtle background particle effects mimicking spice dust
**Pixi.js:** Interactive menu item hover effects
**Matter.js:** Playful physics for floating food elements

### Animation Style
- **Subtle Entrance Animations:** Fade-in with slight upward movement
- **Hover Effects:** Gentle scale and shadow changes
- **Loading States:** Smooth skeleton screens and progress indicators
- **Page Transitions:** Fade overlays maintaining brand colors

### Header Background Effects
- **Liquid Gradient Flow:** Warm yellow to cream gradient with gentle movement
- **Parallax Scrolling:** Subtle depth on hero sections
- **Texture Overlays:** Subtle paper texture reminiscent of old menus

## Interactive Elements

- **Smooth Transitions:** Fade-in/out animations using Anime.js
- **Active States:** Clear visual feedback for selected filters
- **Search Functionality:** Real-time filtering with instant results
- **Category Icons:** Visual representations for each food category

### Hover Effects
- **Card Elevation:** Subtle shadow increase and slight scale
- **Image Zoom:** Gentle zoom on menu item images

### Scroll Motion
- **Reveal Animations:** Content appears as user scrolls

- **Sticky Navigation:** Header transforms on scroll

## Responsive Design

### Mobile Optimization
- **Touch-Friendly:** Minimum 44px touch targets
- **Simplified Navigation:** Collapsible menu with clear hierarchy
- **Optimized Images:** Responsive sizing for faster loading
- **Gesture Support:** Swipe gestures for image galleries

### Tablet Experience
- **Balanced Layout:** Optimal content density for medium screens
- **Enhanced Interactions:** Hover effects adapted for touch
- **Flexible Grids:** Adaptive column layouts
- **Contextual Menus:** Location-aware navigation options

### Desktop Enhancement
- **Rich Interactions:** Full hover effects and animations
- **Multi-Column Layouts:** Efficient use of screen real estate
- **Advanced Features:** Enhanced filtering and search capabilities
- **Immersive Experience:** Full-screen hero sections and galleries

## Accessibility & Performance

### Accessibility Features
- **High Contrast:** 4.5:1 minimum contrast ratio for all text
- **Keyboard Navigation:** Full site navigation without mouse
- **Screen Reader Support:** Semantic HTML and ARIA labels
- **Focus Indicators:** Clear visual focus states for all interactive elements

### Performance Optimization
- **Lazy Loading:** Images load as needed
- **Optimized Assets:** Compressed images and minified code
- **Fast Loading:** Critical CSS inlined, non-critical deferred
- **Smooth Animations:** Hardware-accelerated transforms

This design system creates an authentic, heritage-inspired digital experience that honors Puducherry's unique cultural fusion while providing modern functionality and accessibility.
